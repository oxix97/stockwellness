## Fixed interpretation and handoff

- **Source row:** `stock_price_daily(stock_id, trade_date, quote_scope)` or `index_daily(series_id, trade_date)` with independent data status, observed source, revision and timestamps. NORMAL collection is not automatically FINAL; only verified final sources enter price calculations. Unknown calendar day is not closed day.
- **Price basis:** Current stock technical batch uses `StockPrice.getClosePrice()` (RAW); its redesigned result uses `price_basis=RAW` unless the caller explicitly requests provider adjustment and complete input exists. An `adjClose` field does not imply dividend-reinvested total return. `stock_price_adjustment` may be absent.
- **Index basis:** Existing market cards and simulation benchmark use canonical `PRICE/NONE` with no cross-basis/currency fallback. Actual-investment gross TR requires a verified `TOTAL_RETURN/GROSS` provider series; if unavailable, report unsupported and do not synthesize TR from adjusted price.
- **Units:** Currency ISO code, numeric money/price as decimal contract, daily returns and weights in percent, Sharpe/Beta dimensionless. Trading amount is provider value and is not replaced by close×volume. Foreign/institution net flow is stored in currency units with negatives allowed.
- **IDs:** Keep the JSON number/string shape already published for each route. Exposed numeric bigint IDs are restricted to JavaScript-safe integers. `accountId` path remains a decimal string. Internal Batch IDs follow framework schema.
- **Failure:** Source missing, unsupported basis, incomplete data, holidays, no AI result, and unauthorized resource have separate outcomes; never fill a financial missing value with zero or return raw SQL/AI exception.
- **Compatibility:** Preserve route/envelope/field names where semantics are unchanged. Add EOD/basis/status metadata only after BE/FE OpenAPI fixture comparison. In particular, `ChartDataResponse` contains `date`, raw OHLC, `adjClose` and optional MA fields; `SectorDetailResult` contains baseDate/technicalIndicators/leadingStocks/aiOpinion; `StockSupplyRankingResponse` contains effectiveDate and two lists. A DB table rename alone must not change these responses.
