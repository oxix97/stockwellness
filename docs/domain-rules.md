# 도메인 및 금융 데이터 규칙

## 데이터 의미

- 시장 가격과 지표는 EOD 기준일을 명시한다.
- 금액 및 수익률의 단위, 소수 정밀도, 반올림 정책을 명세 및 구현과 일치시킨다.
- 휴장일, 거래일과 시간대, 데이터 누락, 0/음수, 분모 0 및 경계값을 고려한다.
- AI 설명의 근거와 실제 데이터 경로를 확인하고 검증되지 않은 계산을 사실로 제시하지 않는다.

## 변경 전 점검

1. 실제 도메인 모델과 기존 테스트가 규정하는 의미를 확인한다.
2. API 및 DB 계약의 호환성을 분석한다.
3. 실패 테스트 또는 동등한 검증 증거를 먼저 준비한다.
4. 트랜잭션 경계와 멱등성, 재시도에 따른 중복 반영을 점검한다.

값이나 계산 공식은 기존 코드/명세 확인 전에는 이 문서에 임의로 추가하지 않는다.
